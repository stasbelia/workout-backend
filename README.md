# Workout Tracker backend

Express API для входу, перевірки сесії та приватних аватарів у S3. Потрібні Node.js 24+, PostgreSQL і приватне S3-сховище.

## Тести

```sh
npm ci
npm test
```

Тести використовують вигадані ключі, підставне S3 і PostgreSQL у пам'яті (PGlite). Справжній `.env`, AWS-акаунт чи робоча БД не потрібні.

## Запуск

1. Створити приватний `.env` за `.env.example`. Потрібна таблиця `users` з `id`, унікальною `email`, `password` для bcrypt-хешу та `created_at`.
2. Налаштувати приватний іменований AWS-профіль поза репозиторієм. IAM-дозволи обмежити `GetObject`, `PutObject`, `DeleteObject` для `avatars/*` потрібного bucket.
3. Зробити приватну резервну копію БД та виконати `npm run migrate:avatar`.
4. Запустити `npm start` за HTTPS-проксі. Node за замовчуванням слухає лише `127.0.0.1`; довіряє тільки локальному проксі. Nginx має додавати справжню IP-адресу клієнта праворуч у `X-Forwarded-For` або повністю перезаписувати цей заголовок.

`JWT_SECRET` має бути довгим випадковим секретом щонайменше 32 байти. Приклади конфігурації навмисно не містять робочих значень. Паролі, ключі, дампи БД, журнали та підписані посилання не публікувати.

Докладний цикл аватара й міграція: [AVATAR_UPLOAD.md](AVATAR_UPLOAD.md). Межі захисту та перевірки: [SECURITY.md](SECURITY.md).
